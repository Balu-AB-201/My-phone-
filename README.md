# AB Dialer

A clean, ad-free Android dialer built from scratch.

## Design rule

The user-facing design is based on an original liquid-glass system implemented inside this project. It is not a copy of PhoneX source code or proprietary assets.

The glass system is a first-class UI foundation: translucent depth, directional highlights, specular edges, rounded material and motion will be extended consistently across the app.

## Current milestone

- Native Android + Jetpack Compose
- Original liquid-glass surface foundation
- Dial pad shell
- Contacts entry point
- Favorites entry point
- Call action shell
- No advertising SDKs
- GitHub Actions debug build

## Planned modules
